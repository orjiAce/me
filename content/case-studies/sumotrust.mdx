## Context

Sumotrust is naira savings and investment across mobile and web. I designed
the products through user research, then built them in React Native and
React with TypeScript.

## What I owned

A naira savings system for local-currency deposits earning APY, and — with
a backend engineer — a secure investment and money-gifting system. React
Query for server state, Redux for client state.

## Hard parts

Hardening the clients: console statements stripped in production, keys in
`.env`, tokens in secure store, and biometric or PIN authentication in
front of the money.

## Outcome

Managed funds for **10,000+** users worldwide.
